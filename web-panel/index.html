DNS / TLS SETUP

Domain setup guide

Prepare a hostname for a fresh VPS installation.

Current host Not reported
  1. Create an A record for your hostname pointing to this VPS public IPv4. On the VPS, run curl -4 https://api.ipify.org to check its address.
  2. Wait for DNS to resolve, then check it with getent ahostsv4 your.domain.
  3. Build the installer command below and run it on a fresh Debian 12 VPS. The installer requests a trusted TLS certificate when DNS points to the VPS.

This guide is for a new installation. Do not rerun the installer on a live VPS to change its hostname; existing server domain migration needs coordinated DNS, certificate, Nginx, and VPN endpoint changes.
